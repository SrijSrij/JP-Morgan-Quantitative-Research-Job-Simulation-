# Data Access

The datasets used in this project were supplied through the JPMorgan Chase Quantitative Research Job Simulation on Forage. They are not included in this repository because public redistribution rights have not been established.

Authorized simulation participants can obtain the files through their own Forage access and place them in the repository root using these filenames:

```text
Nat_Gas.csv
Task3and4_Loan_Data.csv
```

The files are listed in `.gitignore` and should not be force-added to a public repository unless the relevant rights holder provides written permission.
